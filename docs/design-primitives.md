# Design Primitives

Общие компоненты этапа 10 основаны на утверждённых шапке и Hero.
Продуктовые требования и визуальное направление по-прежнему определяют документы 01–06.

## Компоненты

| Компонент | Файл в `src/components/ui/` | Применение |
| --- | --- | --- |
| `Container` | `container.tsx` | Максимальная ширина 1280px, отступы 48px / 24px с каждой стороны |
| `ActionLink` | `action.tsx` | Навигация; варианты `primary`, `secondary`, `outline` |
| `Button` | `action.tsx` | Действия; те же варианты, нативный `disabled`, по умолчанию `type="button"` |
| `Heading` | `typography.tsx` | Семантика `h1` / `h2` / `h3` отдельно от размера `display` / `section` / `subheading` |
| `Text` | `typography.tsx` | Основной текст: 16px, line-height 1.75 |
| `Label` | `typography.tsx` | Техническая подпись; `as="p"` или `as="span"`, необязательный `marker` |
| `Section` | `section.tsx` | Светлая или тёмная секция; стандартные отступы или `spacing="none"` |
| `Card` | `card.tsx` | Семантический `article`, тонкая рамка, отступы 32px / 24px, без скругления |
| `ImageFrame` | `image-frame.tsx` | `next/image` с постоянным соотношением сторон и кадрированием `cover` |

Компоненты принимают стандартные HTML-атрибуты и `className`.
Они не требуют `use client`. При необходимости интерактивный компонент может
импортировать их в свою клиентскую границу, как это делает мобильное меню.

## Правила композиции

- `Section` задаёт фон, цвет текста и цвета кнопок. Вариант `tone="light"`
  автоматически делает основные кнопки тёмными. По умолчанию используется `dark`.
- `Container` добавляется внутри секции явно: это позволяет сочетать контент
  ограниченной ширины с фотографиями на всю ширину.
- Вертикальные отступы секции: 128px на desktop, 80px на mobile.
  Hero использует `spacing="none"` и собственную утверждённую композицию.
- `ActionLink` по умолчанию показывает стрелку. У `Button` она выключена;
  `arrow` и `iconSize` позволяют настроить её без изменения стиля кнопки.
- `ImageFrame` требует `alt` и `sizes`. Варианты: `landscape` (16:9),
  `square` (1:1), `portrait` (4:5), `free` (высота задаётся внешним layout).
  Для Hero используется `free` и `preload`; остальные изображения по умолчанию lazy.
- Карточки применяются для услуг, пакетов и метаданных там, где это нужно по спецификации.
- Для действий используется `Button`, для переходов — `ActionLink`.
- Порядок заголовков определяется структурой страницы, а не их визуальным размером.

## Токены

`src/styles/tokens.css` содержит цвета, шрифт, ширину контейнера,
адаптивную типографику, размеры, отступы и длительность переходов.
`src/styles/primitives.css` содержит оформление общих компонентов.
`src/app/layout.tsx` напрямую подключает файлы токенов и примитивов, затем
`src/app/globals.css` со стилями конкретной композиции шапки, Hero и мобильного меню.
Порядок CSS layers задан явно, а токены темы публикуются через `@theme static`.

Шкала отступов в px: **4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128**.
Имена `--space-N` соответствуют шагу 4px, например `--space-6: 24px`.
Точные значения внутри утверждённого Hero сохранены, включая значения вне основной шкалы.

Все кнопки сохраняют видимые focus-состояния; общие переходы учитывают reduced motion.

## Проверка этапа

Production-сборка и проверка TypeScript прошли. Проверены адаптивность,
кадрирование, hover/focus, reduced motion и клавиатурное управление меню.
Скриншоты после выделения компонентов совпали с утверждёнными скриншотами этапа 9
на 390, 768, 1024 и 1440px: **0 изменённых пикселей**.
