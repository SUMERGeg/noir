# Этап 13 — Project Template

Реализованы `/projects` и `/projects/porsche-911-carrera-4s`.

Шаблон кейса включает Hero, сведения об автомобиле, задачу, выполненные
работы и процесс, технические данные, галерею, сравнение покрытия, результат,
связанную услугу и CTA. Статичные секции — Server Components; интерактивность
сравнения использует существующий компонент с перетаскиванием на фотографии.

Контент хранится в `src/content/project-cases.ts` и связан с утверждёнными
проектами из `projects.ts`. Из него формируются список, статические маршруты
и metadata. Неизвестные slug возвращают 404. Сейчас утверждён один кейс;
остальные добавляются через данные при наличии контента.

Технические данные сохранены: плёнка 184 мкм, 32 часа работы, гарантия 10 лет.
Галерея использует существующие концептуальные иллюстрации. Сравнение помечено
как иллюстрация коррекции, оно не выдаётся за фотографии этого автомобиля.

CTA ведёт к форме контактов этапа 14 с выбранной услугой PPF.
Production metadataBase / canonical и Lighthouse остаются для подготовки
к публикации и этапа 17.
