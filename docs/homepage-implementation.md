# Этап 11 — Homepage

Основа: утверждённые `03-content.md`, `04-visual-direction.md`,
`05-site-spec.md` и компоненты этапа 10. Hero сохраняется.

## Реализация

1. Типизированные данные: показатели, материал, шесть шагов, финальный CTA.
   Русские переводы утверждённого текста без новых обещаний и цифр.
2. Секции по порядку: credibility, services, featured project, technology,
   process, before/after, pricing, reviews, final CTA; общий footer.
3. Server Components для статичных секций. Только сравнение изображений —
   Client Component с нативным range input, поддержкой мыши, touch и клавиатуры.
4. Локальные оптимизированные WebP, заданные пропорции и responsive sizes.
   Новые изображения — концептуальные иллюстрации. Сравнение явно помечено
   как визуализация; источники и prompts записываются в `public/images/README.md`.
5. Проверка production-сборки и критериев текущего этапа. Проверка в браузере
   выполняется только при разрешённом доступе инструмента; ограничения
   фиксируются, визуальная проверка не подменяется проверкой компиляции.

Маршруты услуг, проектов, цен и контактов реализуются на этапах 12–14.
Декоративная анимация — этап 15. Новые зависимости не нужны.

## Прогресс

- Реализованы данные, все секции, сравнение, адаптивные стили и footer.
- Английские редакционные названия сохранены, переводы основного текста
  записаны в `03-content.md` и типизированных content-файлах.
- Production-сборка и TypeScript: успешно, 2026-09-30.
- По артефактам сборки проверены порядок восьми секций, четыре услуги,
  три пакета и три отзыва, единственный h1, семантика range input,
  локальные изображения и включение CSS. Это не браузерная проверка.
- Статичное содержимое пререндерено; новый Client Component — ImageComparison.
- Краткое независимое ревью кода новых секций, контента, responsive CSS
  и сравнения выполнено: существенных замечаний не обнаружено.
  Ревью исходников не подтверждает поведение страницы в браузере.
- 2026-09-30 доступ к Browser Use восстановлен: локальный сервер был остановлен,

  Сервер запущен, сам сайт открыт по HTTP во встроенном браузере Codex.
- Проверены отсутствие горизонтального overflow на 390/768/1024/1440px,
  Hero на desktop/mobile и загрузка изображений сравнения. Range input

  прозрачным слоем на фотографию. Его thumb совмещён с круглым маркером;
  видимый focus выделяет маркер, инструкции доступны скринридеру.
  Проверены перетаскивание 50→80 с изменением clipping, стрелки,
  Home/End (0/100), отсутствие overflow на четырёх ширинах и консоль.
  Production-сборка и TypeScript прошли. Скриншот:
  `.npm-cache/qa/comparison-drag-mobile.png`.
