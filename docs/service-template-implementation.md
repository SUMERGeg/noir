# Этап 12 — Service Template

## Реализовано

- `/services/ppf`: десять секций по `05-site-spec.md`, отдельный Hero,
  описание, преимущества, выбор зон защиты, процесс, два PPF-пакета,
  материал, гарантия, FAQ и финальный CTA.
- Композиция `ServicePage`, отдельные секционные компоненты и типизированные
  данные `service-pages.ts`. Статичные Server Components; FAQ использует
  нативные `details` / `summary`, дополнительных зависимостей нет.
- Цены и комплектация берутся из существующих `services.ts` и `pricing.ts`.
  CTA передают услугу или пакет в будущую форму контактов.
- Уникальные title, description и Open Graph. Адрес production-сайта для
  metadataBase / canonical будет задан при подготовке к публикации.

## Проверка — 2026-09-30

- Production build и TypeScript успешно; маршрут статически генерируется.
- Во встроенном браузере проверены 390, 768, 1024 и 1440 px:
  горизонтального переполнения нет, первый экран и изображения адаптируются.
- Переход «Выбрать пакет» открывает нужную секцию.
- FAQ раскрывается Enter и закрывается Space; клавиатурный фокус виден.
- Ошибок в консоли при проверке не обнаружено.
- Новая анимация не добавлялась. Полные Lighthouse-аудиты относятся к этапу 17.

Визуальное утверждение PPF пользователем, затем перенос структуры на остальные
услуги. Контакты и форма заявки остаются задачей этапа 14.
