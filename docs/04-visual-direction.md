# 04 — Visual Direction & References

## Goal

Create a premium automotive atelier aesthetic rather than a generic detailing website.

## Reference Formula

- 35% Singer Vehicle Design
- 25% Polestar
- 20% Stalla
- 10% Topaz Detailing
- 10% RIMOWA / Aesop

# Color System

## Warm Black

`#0B0B0B`

## Off White

`#F1F0EC`

## Graphite

`#1A1A1A`

## Steel

`#A7A9A7`

## Color Principle

Do not use a constant accent color across the whole site.

Let the featured vehicle provide the accent color where possible.

Examples:

- silver Porsche → silver visual tone;
- green Range Rover → restrained green accents;
- red Ferrari → restrained red accents.

---

# Typography

## Display

Direction:

- geometric/editorial grotesk;
- large scale;
- controlled line height;
- premium but not fashion-cliché.

Avoid:

- racing fonts;
- techno fonts;
- over-condensed tuning typography.

## Body

- neutral grotesk;
- high readability;
- calm density.

## Scale

Hero:

- 64–120px desktop
- 36–52px mobile

Section headings:

- 40–64px

Body:

- 16–20px

Technical metadata:

- 11–14px
- uppercase
- tracking

---

# Photography

Use:

- macro paint reflections;
- PPF installation;
- wheel / brake / carbon details;
- hands at work;
- clean workshop;
- controlled lighting;
- before / after;
- premium cars;
- material texture.

Avoid:

- generic stock supercars;
- random urban backgrounds;
- fake neon;
- heavy HDR;
- over-processed imagery.

---

# Layout

Recommended max content width:

`~1280px`

Principles:

- generous whitespace;
- full-width photography;
- asymmetry where useful;
- alternating dark and off-white sections;
- not every section should use cards;
- visual pacing matters.

---


---

# UI

## Buttons

Primary:

- solid light on dark;
- dark on light;
- low radius;
- no glow.

Secondary:

- text + arrow.

## Cards

Use sparingly.

Appropriate for:

- service previews;
- package options;
- project metadata.

## Borders

Thin, low contrast.

## Radius

Small to medium.

Avoid generic 20–24px SaaS rounding everywhere.

---

# Motion

Allowed:

- slow image reveal;
- text fade/rise;
- subtle scale;
- 1–3% image zoom on hover;
- page transitions;
- before/after interaction;
- restrained parallax.

Avoid:

- bouncing;
- neon glow;
- floating elements;
- animated gradients;
- every section using a different entrance effect.

Principle:

> Motion should communicate precision, not show off an animation library.
