# Этап 15 — Motion

## Реализация

- Общий клиентский контроллер `PageMotion` использует уже установленный `motion/mini`.
  Страницы, секции, типографика и фотографии остаются Server Components.
- Заголовки h2 появляются при входе в экран: opacity 0.15 → 1,
  translateY 32px → 0, длительность 1100ms.
- Контентные фотографии: opacity 0.25 → 1, scale 1.08 → 1 за 1500ms.
  Масштабируется фотография внутри существующей рамки; размеры блока сохраняются.
- Фотографии проекта и галереи увеличиваются на 6% при hover на устройствах с мышью,
  длительность перехода — 1100ms.
- Первый экран, preload-изображения, фоновые фотографии, форма и интерактивное
  сравнение не скрываются и не задерживаются. Без JavaScript весь контент виден.
- При `prefers-reduced-motion: reduce` эффекты отключены. Изменение настройки
  во время работы останавливает активные анимации и восстанавливает стили.
- При переходе по маршрутам наблюдатель и активные анимации очищаются.
  После завершения эффекта исходные inline-стили восстанавливаются.
- После полного выхода элемента за пределы экрана появление готово к повторному
  запуску при прокрутке в любую сторону. Колебания у порога 12% не перезапускают
  эффект, пока элемент остаётся видимым. При выходе незавершённый эффект отменяется.

## Проверка первоначальной реализации (30 сентября 2026)

- Production-сборка и TypeScript успешны.
- В браузере зафиксированы промежуточные кадры появления заголовка:
  opacity 0.65 → 0.81 → 0.98 → 1 и сдвиг 12px → 0.
- Проверена фотография: opacity 0.8 → 1, scale 1.02 → 1. Повторная
  прокрутка не запускает появление заново.
- Главная, PPF, кейс Porsche и контакты проверены на 390/768/1024/1440px:
  нет горизонтального переполнения и обрезанных видимых заголовков.
- Проверен клиентский переход с главной на PPF; первый экран полностью видим.
- Сравнение покрытия управляется клавиатурой: 50 → 51.
- В захваченной консоли ошибок нет. Проведено отдельное ревью кода анимаций.
- Reduced motion проверен по коду контроллера и CSS. Принудительное переключение
  этой настройки в браузере не проверялось: доступный интерфейс эмуляции
  предоставляет только размер viewport.

Общий Responsive QA относится к этапу 16, Lighthouse-аудиты — к этапу 17.

## Корректировка 1 октября 2026

появления. Логика однократного запуска, cleanup и reduced motion сохранена.
Production-сборка успешна. В браузере подтверждены новые промежуточные кадры
заголовка (opacity 0.15, сдвиг 32px), фотографии (opacity 0.25, scale 1.08)

не имеет горизонтального переполнения и обрезанных заголовков; ошибок консоли нет.

Добавлен повторный запуск появления после полного выхода элемента из экрана,
без обновления страницы. Reduced motion и немедленная видимость первого экрана сохранены.
В браузере подтверждены два запуска подряд без reload, повтор при прокрутке вверх
и повторное появление фотографии на 390px. При уходе с экрана незавершённый эффект
сбрасывается. Проверены 390/768/1024/1440px: переполнений и обрезанных заголовков нет,
ошибок консоли нет. Production-сборка и TypeScript успешны.

## Сброс заголовков вне экрана — 1 октября 2026

Заголовки вне viewport заранее получают начальные opacity 0.15 и translateY 32px,
включая повторный выход из экрана. Это исключает скачок из конечной позиции
в начальную при быстрой прокрутке. Проверка выхода учитывает исходную позицию
заголовка без анимационного сдвига, чтобы сброс не вызывал самоперезапуск.
Первый экран остаётся сразу видимым; cleanup и включение reduced motion
восстанавливают исходные стили всех подготовленных заголовков.

В браузере подтверждены начальное состояние до прокрутки, промежуточные кадры
появления и повторный запуск без reload. Production-сборка и TypeScript прошли.
