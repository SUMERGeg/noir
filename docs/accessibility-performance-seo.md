# Этап 17 — Accessibility / Performance / SEO

Дата: 2026-10-01. Этап выполнен по `docs/06-acceptance-criteria.md`.

## Исправления

- Введён единый `pageMetadata`: canonical каждого маршрута, Open Graph URL,
  название сайта, язык и Twitter Card с изображением.
- В корневом layout задан `metadataBase`; предупреждение сборки исчезло.
- `SITE_URL` задаёт публичный origin для метаданных, robots и sitemap.
  Образец находится в `.env.example`, инструкция — в README.
- Canonical страниц PPF, цен и контактов не содержит параметров выбранных зон
  и пакетов; выбор в интерфейсе и перенос в заявку сохраняются.
- Добавлены `sitemap.xml` с 11 страницами и `robots.txt` со ссылкой на sitemap.
- Название ссылки логотипа формируется из его текста и скрытого пояснения
  «— главная», без переопределения через `aria-label`.
- Доступные названия маркеров Porsche включают видимые номера 01–04
  и названия деталей. Устранены замечания `label-content-name-mismatch`.

## Метод проверки

Production-сборка: `node node_modules/next/dist/bin/next build` — успешно,
включая TypeScript strict. Для измерений она запускалась отдельно на порту 3001.

Lighthouse 12.8.2 из официального npm-пакета, Chrome 154, Node.js 22.14.0.
Запуски последовательные, отдельный профиль Chrome, стандартный mobile-профиль
412×823, DPR 1.75, simulated throttling с замедлением CPU ×4.
Desktop — стандартный `--preset=desktop`. Сервер и оптимизатор изображений
локальные; браузерный кеш сбрасывается Lighthouse.
Lighthouse установлен в игнорируемом npm-кеше, зависимости приложения не изменены.

## Браузерная и HTTP-проверка

- Во встроенном браузере проверены метаданные и семантика всех 11 страниц,
  дополнительно три URL с параметрами выбора зон: canonical, description,
  Open Graph, Twitter Card, `lang="ru"`, один h1, отсутствие повторяющихся id
  и изображений без атрибута alt. Все проверки прошли.
- Все 11 маршрутов sitemap, сам sitemap и robots отвечают HTTP 200.
- Проверены 34 уникальные внутренние ссылки с параметрами и якорями:
  неработающих маршрутов и отсутствующих якорей нет.
- На 390/768/1024/1440px проверены логотип, Hero и отсутствие overflow.
  Клавиатурный фокус логотипа виден.
- На 390px проверены открытие крупного плана с нового названия маркера,
  Escape и возврат фокуса на исходный маркер. Ошибок консоли нет.
- Полные проверки меню, формы, PPF, сравнения и диалога выполнены на этапе 16:
  `docs/responsive-qa.md`. Reduced motion проверен по реализации;
  системная настройка ОС в этом этапе не переключалась.

## Артефакты и границы

В `.npm-cache/qa/stage-17/` сохранены итоговые HTML/JSON-отчёты Lighthouse,
`lighthouse-summary.json`, `metadata-dom.json`, `links-and-crawling.json`,
`console-errors.json`, снимки экрана и скрипт повторного запуска аудитов.

Это лабораторные измерения локальной production-сборки, а не полевые Web Vitals
посетителей опубликованного сайта. Проверка настоящим экранным диктором,
Safari и физическими устройствами не проводилась.
При деплое на этапе 19 необходимо задать настоящий `SITE_URL` до сборки:
локальный fallback — `http://localhost:3000`. После публикации нужны контрольные
измерения на публичном URL с реальной сетью и HTTPS.

Использованные первичные руководства:
[Lighthouse CLI](https://github.com/GoogleChrome/lighthouse/blob/main/readme.md),
[Next.js Metadata](https://nextjs.org/docs/app/api-reference/functions/generate-metadata),
[Sitemap](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/sitemap),
[Robots](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/robots).
